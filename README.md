# brief_meteo
## Description
Cette application web permet d'afficher les informations météorologiques d'une ville spécifique. Elle utilise l'API OpenWeatherMap pour récupérer les données météorologiques en temps réel et les affiche dans une interface utilisateur.
Documentation: https://openweathermap.org/api
## Pour commencer
Ajouter votre nom de ville et pays dans le fichier `conf.json`.
Et renseigner votre clé api dans un fichier à créer env

créer ce fichier `env.js`
